# 🌟 Super App

A modern, multi-functional, fully responsive, and highly interactive dashboard web app that combines entertainment, real-time weather, news, and utility widgets-all in a beautifully designed interface.

## 🌄 Description :--

- Create an account
- Choose their entertainment preferences
- View curated content suggestions
- Track time and weather in real-time
- Read the latest news headlines
- Access a visual countdown timer and notepad

## ✨ Features :--

📝 User signup form with name, email, mobile input  
🎭 Choose your favorite entertainment genres (at least 3)  
🎬 Curated movie/music suggestions based on your picks  
🕒 Live clock and calendar display  
🌦️ Real-time weather info (temperature, humidity, wind, etc.)  
📰 News card showing latest global headlines  
⏱️ Countdown timer  
📒 Yellow sticky notepad for writing notes  
🎨 Visually vibrant and responsive layout

## 🛠️ Technologies :--

⚡ Vite.js

⚛️ React.js  
💅 CSS3  
🌐 HTML5  
🧠 JavaScript (ES6+)  
🚀 Deployed on Vercel

## 🚀 Usage :--

1. **Sign up** with your details.
2. **Choose** at least three entertainment categories.
3. **Explore** recommended content based on your selection.
4. **Track** real-time weather and current time.
5. **Use** the countdown timer and note-taking widgets.
6. **Read** the latest global news.
